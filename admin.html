Twilio WhatsApp Setup

Connect your Twilio account to receive and reply to WhatsApp messages automatically.

Setup checklist (expand)
  1. Create a Twilio account at twilio.com
  2. Go to Messaging → Try WhatsApp → activate sandbox
  3. Set the sandbox When a message comes in webhook to:
    POST https://YOUR_DOMAIN/whatsapp/incoming
  4. For production: request a WhatsApp Business number in Twilio console
  5. Add TWILIO_ACCOUNT_SID and TWILIO_AUTH_TOKEN to .env
  6. Add OPENAI_API_KEY in the AI Brain section above
  7. Restart the server: npm start
  8. Test by sending a WhatsApp message to your Twilio number

Twilio Setup

Add these to your .env file then restart the server. The agent is fully hosted on your Node backend — no third-party dashboard needed.

# .env — paste into your project root
TWILIO_ACCOUNT_SID=ACxxxxxxxxxx
TWILIO_AUTH_TOKEN=your_token

TRANSFER_NUMBER=+1xxxxxxxxxx
GEMINI_API_KEY=AIza... (from aistudio.google.com)
Twilio configuration checklist (expand)
  1. Create a Twilio account at twilio.com (free trial includes a phone number)
  2. Get a Twilio phone number → Phone Numbers → Manage → Buy a Number
  3. Set the Voice webhook on that number → https://your-domain.com/voice/incoming (POST)
  4. Set the Status callback URL → https://your-domain.com/voice/status
  5. Add your GEMINI_API_KEY so ARIA can generate intelligent responses
  6. Deploy your server publicly (use ngrok for local testing: ngrok http 3000)
  7. Call your Twilio number — ARIA answers automatically!
